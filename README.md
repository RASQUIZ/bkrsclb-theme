# bkrsclb-theme

Shopify theme source for **bkrsclb.com** (BKRSCLB store) — "Fabric - Android Download Banner" theme.

This is a one-time export snapshot (downloaded from Shopify admin on 2026-08-15), not a live-synced copy. The live theme still lives in Shopify; this repo exists to give tools like Claude Design a real source of the theme's components, styles, and structure — not as the store's deployment pipeline.

To pull a fresh snapshot later: Shopify admin → Online Store → Themes → "..." on the live theme → **Download theme file**, then replace the contents of this repo (excluding `.git`) and commit.
